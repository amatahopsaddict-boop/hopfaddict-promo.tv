เปิด index.html เพื่อเลือก admin.html หรือ tv.html
เปิด admin.html และ tv.html ในแท็บของเบราว์เซอร์เดียวกันเพื่อทดสอบการอัปเดตทันที
อัปโหลดภาพเพิ่มเติมได้ และเปิด/ปิด/จัดลำดับภาพได้
ภาพที่อัปโหลดเก็บใน IndexedDB ของเบราว์เซอร์ ข้อมูลข้อความเก็บใน localStorage

ข้อจำกัด: เป็นเดโมแบบ local ไม่ได้ซิงก์ข้ามมือถือกับ Android TV Box
ถ้าเปิดผ่าน file:// เบราว์เซอร์บางตัวอาจจำกัดการแชร์ข้อมูลระหว่างหน้า
แนะนำรันเว็บผ่าน HTTP localhost หรือ HTTPS Hosting
หน้าจอ admin ยังไม่มีระบบ login: อย่าเปิดเผยบนอินเทอร์เน็ตโดยไม่เพิ่ม authentication/security rules
QR ต้องใส่ลิงก์ HTTPS จริงในแอดมิน และใช้บริการ QR ภายนอก จึงต้องมีอินเทอร์เน็ต

เวอร์ชัน V4: เพิ่ม export.html ส่งออกสไลด์เป็นวิดีโอสำหรับ Facebook
- เปิด admin.html เพื่อเพิ่มภาพและแก้เนื้อหา จากนั้นเปิด export.html

- วิดีโอไม่มีเสียง และ QR จากบริการภายนอกไม่ได้รวมในวิดีโอ
